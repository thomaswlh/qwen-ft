## 3. 从零装一套能跑的环境

下面是 **2026-09-22 重装 `qwen-ft` 并跑通 SFT + GRPO 的实际顺序**。不要照抄 `pip install "verl[vllm]"`：它会把 torch / vLLM 升到和本机驱动不兼容的版本。

### 3.1 激活 lxhu conda

```bash
source /home/jpzhao_team/lxhu/miniconda3/bin/activate
```

### 3.2 建干净的 Python 3.12 环境

旧 env 若是 cu130 / `megatron-core==0.12.3`，直接删掉重建，不要在坏栈上覆盖：

```bash
# 先退出该 env，并清掉 CONDA_PREFIX，否则 conda env remove 会失败
conda deactivate
unset CONDA_PREFIX CONDA_DEFAULT_ENV CONDA_SHLVL
conda env remove -n qwen-ft -y
conda create -n qwen-ft python=3.12 -y
conda activate qwen-ft
```

### 3.3 先装匹配驱动的 PyTorch

驱动是 CUDA 12.9，必须从 **PyTorch 官方 cu128 源**装，不要走默认 PyPI（会拉到不带 `+cu128` 的 `torch==2.10.0`）：

```bash
pip install torch==2.10.0 torchvision==0.25.0 torchaudio==2.10.0 \
  --index-url https://download.pytorch.org/whl/cu128
```

不要装 `cu130` / `torch==2.11.0+cu130`。

检查：

```bash
python - <<'PY'
import torch
print(torch.__version__, torch.version.cuda, torch.cuda.is_available())
x = torch.zeros(1, device="cuda")
print("ok", torch.cuda.get_device_name(0))
PY
```

应看到 `2.10.0+cu128` 且 `True`。

### 3.4 装 vLLM（锁住 torch）

```bash
pip install "vllm==0.19.1" "torch==2.10.0"
python -c "import torch,vllm; print(torch.__version__, vllm.__version__, torch.version.cuda)"
```

必须仍是 `2.10.0+cu128` 和 `vllm 0.19.1`。vLLM 可能把 `transformers` 拉到 5.17，后面要降回 **5.8.1**。

### 3.5 装 Megatron / verl（不要带 extras）

`megatron-bridge==0.5.1` 的 PyPI 依赖会要 `flashinfer==0.6.8`、TE、mlflow、comet 等。那些和本机 vLLM / 无 TE 栈冲突。**用 `--no-deps`**：

```bash
pip install --no-deps megatron-core==0.18.2
pip install --no-deps megatron-bridge==0.5.1
pip install --no-deps verl==0.9.0
```

再写一份约束，避免后续 pip 把 torch / vLLM / flashinfer 换掉：

```bash
cat > /tmp/qwen-ft-constraints.txt <<'EOF'
torch==2.10.0+cu128
torchvision==0.25.0+cu128
torchaudio==2.10.0+cu128
vllm==0.19.1
flashinfer-python==0.6.6
flashinfer-cubin==0.6.6
EOF

pip install -c /tmp/qwen-ft-constraints.txt \
  "transformers==5.8.1" \
  "ray[default]==2.58.0" \
  "peft==0.20.0" \
  "datasets==5.0.1" \
  "hydra-core==1.3.2" \
  "omegaconf==2.3.1" \
  "accelerate==1.14.0" \
  "tensordict==0.10.0" \
  "nvidia-modelopt[torch]==0.46.0" \
  "nvidia-resiliency-ext==0.4.1" \
  "TransferQueue==0.1.10" \
  "diffusers==0.40.0" \
  "qwen-vl-utils" \
  pyarrow pandas \
  codetiming pylatexenc pybind11 torchdata wandb tensorboard \
  --upgrade-strategy only-if-needed
```

`verl` 需要 `transformers!=5.6.0,<5.11,>=5.5.3`，`megatron-bridge` 需要 `transformers>=5.8.1,<5.9`。交叉点就是 **5.8.1**。

`TransferQueue` 不装的话，`verl.trainer.main_ppo` 会在 Ray worker 里报 `No module named 'transfer_queue'`。

### 3.6 无 TE 本地补丁（必做）

PyPI 原版 `megatron-bridge==0.5.1` 会 `import transformer_engine`。本机没有 TE。从已跑通的环境拷补丁（文件内容就是把 TE 改成可选 import）：

```bash
SRC=/home/jpzhao_team/zymo/verl_env/lib/python3.12/site-packages
DST="$CONDA_PREFIX/lib/python3.12/site-packages"

cp "$SRC/megatron/bridge/models/gpt_provider.py" \
   "$DST/megatron/bridge/models/gpt_provider.py"
cp "$SRC/megatron/bridge/peft/lora_layers.py" \
   "$DST/megatron/bridge/peft/lora_layers.py"
cp "$SRC/megatron/bridge/peft/lora.py" \
   "$DST/megatron/bridge/peft/lora.py"
cp "$SRC/megatron/bridge/peft/utils.py" \
   "$DST/megatron/bridge/peft/utils.py"
cp "$SRC/megatron/core/dist_checkpointing/strategies/nvrx.py" \
   "$DST/megatron/core/dist_checkpointing/strategies/nvrx.py"
cp "$SRC/megatron/core/transformer/dot_product_attention.py" \
   "$DST/megatron/core/transformer/dot_product_attention.py"

# pip 装的 nvidia-resiliency-ext 0.4.1 没有 __init__.py，bridge import 会炸
echo '__version__ = "0.4.1"' > "$DST/nvidia_resiliency_ext/__init__.py"
```

重装 `megatron-core` / `megatron-bridge` / `nvidia-resiliency-ext` 后要再打一次。

### 3.7 重建 config 软链

`config/` 指向 **当前 env 里 verl 0.9** 的 trainer yaml。换了 verl 必须重链：

```bash
  /home/jpzhao_team/lxhu/workspace/qwen-ft/config
```

| 包 | 为什么跳过 |

| `flash-attn` | 本机没编过；脚本默认 `unfused` |

```bash

  trainer.total_epochs=1 trainer.total_training_steps=4 \
  data.train_batch_size=8 data.micro_batch_size_per_gpu=1 data.max_length=768
```

```bash
ln -sfn checkpoints/gsm8k_sft/global_step_<N>/model/huggingface output/latest_hf
```

## 6. 版本坑（装错会直接起不来）

1. **torch CUDA 必须 ≤ 驱动**。本机驱动 12.9 → 用 cu128，禁用 cu130。
2. **不要用默认 PyPI 再装一遍 `torch==2.10.0`**，会覆盖掉 `+cu128` wheel。
3. **`megatron-core` 和 `megatron-bridge` 要配对**。bridge 0.5.1 需要带 `megatron.core.distributed.fsdp` 的 mcore（本机验证过 0.18.2）。`0.12.3` 会 import 失败。
4. **vLLM 和 torch 要配对**。工作组合是 `torch 2.10.0+cu128` + `vllm 0.19.1`。
5. **`transformers` 锁 5.8.1**。vLLM 默认拉上来的 5.17 过新，verl / bridge 都会拒。
6. **GRPO 必须有 `TransferQueue`**。
7. **不要给 GRPO 开** `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`，vLLM 会 assert。
8. 共享卡上 `vllm gpu_memory_utilization` 按整卡容量算，不是按剩余显存。默认 `0.15`；更挤就 `VLLM_GPU_UTIL=0.10`。
