## 3. 从零装一套能跑的环境

下面装的是 **已跑通的 `zymo/verl_env` 版本组合**。可以装进现有 `qwen-ft`，也可以新建一个 env。

### 3.1 激活 lxhu conda

```bash
source /home/jpzhao_team/lxhu/miniconda3/bin/activate
```

### 3.2 建 Python 3.12 环境

已有 `qwen-ft` 且准备覆盖重装：

```bash
conda activate qwen-ft
```

新建（推荐，避免和坏掉的 cu130 缠在一起）：

```bash
conda create -n qwen-ft-cu128 python=3.12 -y
conda activate qwen-ft-cu128
```

### 3.3 先装匹配驱动的 PyTorch

驱动是 CUDA 12.9，必须装 **cu128** wheel：

```bash
pip install torch==2.10.0 torchvision==0.25.0 torchaudio==2.10.0 \
  --index-url https://download.pytorch.org/whl/cu128
```

不要装 `cu130` / `torch==2.11.0+cu130`。

检查：

```bash
python - <<'PY'
import torch
print(torch.__version__, torch.version.cuda, torch.cuda.is_available())
x = torch.zeros(1, device="cuda")
print("ok", torch.cuda.get_device_name(0))
PY
```

应看到 `2.10.0+cu128` 且 `True`。

### 3.4 装 vLLM、Megatron、verl、Ray

顺序建议：torch → vLLM → Megatron → verl。vLLM 会再拉一批 CUDA 依赖，装完后确认 `torch` 仍是 cu128。

```bash
pip install vllm==0.19.1
pip install megatron-core==0.18.2 megatron-bridge==0.5.1
pip install "verl[vllm]==0.9.0"
pip install ray==2.58.0 peft==0.20.0 datasets==5.0.1 \
  "transformers>=4.57,<6" hydra-core==1.3.2 omegaconf==2.3.1 \
  accelerate==1.14.0 TransferQueue==0.1.10 pyarrow pandas
```

`verl[vllm]` 可能把 vLLM / torch 升到不兼容版本。装完立刻复查：

```bash
python -c "import torch,vllm,verl,megatron.core,megatron.bridge,ray; \
print(torch.__version__, vllm.__version__, verl.__version__)"
```

若 torch 被改成 cu130，立刻卸掉重装 3.3 那一行。

官方备选（版本不要锁死时再用）：

```bash
pip install "verl[vllm]"
# 或源码：git clone https://github.com/volcengine/verl.git && pip install -e ".[vllm,math]"
```

### 3.5 不必装的包

| 包 | 为什么跳过 |
|---|---|
| `flash-attn` | 本机没编过；脚本默认 `unfused` |
| `transformer-engine` / Apex | 同样没有；`masked_softmax_fusion=False` |
| `wandb` | 日志默认只打 console |

以后要练 Flash：`FLASH=1 bash scripts/run_sft.sh`。失败就改回 `FLASH=0`。

### 3.6 让脚本用新环境

覆盖 `qwen-ft` 且 3.3 的 CUDA 检查已通过：什么都不用改，`env.sh` 会直接用它。

用了新 env 名，或仍想走 `verl_env`：

```bash
export VERL_PYTHON=/path/to/env/bin/python
# 或改 scripts/env.sh 里的 QWEN_FT_ENV / ZYMO_PY
```

`config/` 是指向 **qwen-ft 里 verl 0.9** 的软链。换了一套 verl 安装后，把软链改到新环境的 `site-packages/verl/trainer/config`：

```bash
ln -sfn "$(python -c 'import verl,os; print(os.path.join(os.path.dirname(verl.__file__), "trainer/config"))')" \
  /home/jpzhao_team/lxhu/workspace/qwen-ft/config
```

## 6. 版本坑（装错会直接起不来）

1. **torch CUDA 必须 ≤ 驱动**。本机驱动 12.9 → 用 cu128，禁用 cu130。
2. **`megatron-core` 和 `megatron-bridge` 要配对**。bridge 0.5.1 需要带 `megatron.core.distributed.fsdp` 的 mcore（本机验证过 0.18.2）。
3. **vLLM 和 torch 要配对**。工作组合是 `torch 2.10.0+cu128` + `vllm 0.19.1`。
4. **不要给 GRPO 开** `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`，vLLM 会 assert。
5. 共享卡上 `vllm gpu_memory_utilization` 按整卡容量算，不是按剩余显存。默认 `0.15`；更挤就 `VLLM_GPU_UTIL=0.10`。
